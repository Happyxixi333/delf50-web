# DELF50 Web

A1+ → DELF B1 的 50 天网页备考训练系统。

## 当前版本

V1.6.0

当前生产地址：`https://delf50-mvp.vercel.app`

## 核心原则

- 每日学习强度可选 5 小时 / 6.5 小时 / 8 小时。
- 强度变化真实联动语法、听力、阅读、写作、口语、应用、词块与复习题量。
- 语法训练不只做选择题，同时记录主动造句、改写与口头调用训练证据。
- Day 1–18：A1+ → A2/A2+ 基础与语法自动化。
- Day 19–30：应用迁移。
- Day 31–40：DELF B1 四项专项。
- Day 41–50：模拟、错因定位与提分。
- 用户可以提前浏览或学习后续 Day，但不会自动补齐之前进度。
- 语法、阅读、听力只显示基于客观题的正确率；写作与口语在没有可靠评分器前不生成虚假能力百分比。
- 学习状态保存在浏览器 localStorage；口语录音使用 IndexedDB；支持 JSON 学习备份导出/导入。

## V1.6 内容规模

- 18 个高收益语法节点；Présent 当前约 12 道客观题，多数重点节点约 10 道，并配主动产出训练。
- 阅读 24 篇，按 Day 分阶段开放。
- 听力 24 组，按 Day 分阶段开放。
- 写作 24 项，从 60–70 词逐步过渡到 DELF 阶段 ≥160 词。
- 口语 24 项，覆盖基础表达、叙事、建议、互动、观点和 DELF 三类口试任务。
- 应用情境 24 项，覆盖服务、交通、住房、健康、学习、工作、消费和协商。
- 语法页增加“目标 → 核心规则 → 高频陷阱 → 离开选择题后的练法”。
- 阅读增加主旨复述、词块提取和改写；听力采用三遍诊断法；写作增加计划/检查支架；口语增加回听证据清单。

## 每日强度配额

- 5 小时：语法客观题 8、主动产出 6、应用 2、听力 2、阅读 2、写作 1、口语 2；词块约 25，复习约 10。
- 6.5 小时：语法客观题 10、主动产出 8、应用 3、听力 3、阅读 3、写作 1、口语 3；词块约 35，复习约 15。
- 8 小时：语法客观题 12、主动产出 10、应用 4、听力 4、阅读 4、写作 2、口语 4；词块约 45，复习约 20。

高强度只增加当前阶段的不同材料、主动输出与复盘，不通过提前引入后续语法来凑时间。

## 稳定启动机制

首屏静态 HTML 永远可见，不依赖 JavaScript 成功启动，因此资源异常时也不会白屏。

浏览器仍使用已经通过用户测试的 13/13 稳定启动链：先从 Vercel 同域 `/api/source` 下载全部 13 个模块，全部成功后才按固定顺序执行。服务器端会把历史代码中的浏览器全局冲突 `top()` 转换为 `pageTop()`，并在返回脚本前执行 JavaScript 编译检查。

V1.6 内容层保存在独立文件 `v16-depth.js`。为避免增加客户端启动请求，Vercel 在服务器端把它追加到第 13 个内容模块后再返回，因此浏览器端仍保持 13 个请求和原有初始化顺序。

## 进度评估原则

初始化为 0 / 未评估。只有实际答题、写作提交、应用提交、口语录音或任务完成后才更新记录。

- 语法 / 阅读 / 听力：可显示基于真实客观题的正确率。
- 写作：记录字数、连接表达、段落和完成次数，不冒充 DELF 分数。
- 口语：记录真实录音时长、完成次数和回听自检，不将完成次数伪装成口语水平。
- 跳到未来 Day 不会自动提高任何能力指标。
