# DELF50 Web

A1+ → DELF B1 的 50 天网页备考训练系统。

## 当前版本

V1.3

核心原则：

- 每日学习强度可选 5 小时 / 6.5 小时 / 8 小时。
- 强度变化会真实联动语法、听力、阅读、写作、口语、应用与复习题量。
- Day 1–18：A1+ → A2/A2+ 基础与语法自动化。
- Day 19–30：应用迁移。
- Day 31–40：DELF B1 四项专项。
- Day 41–50：模拟、错因定位与提分。
- 用户可以提前浏览或学习后续 Day，但不会自动补齐之前进度。
- 语法、阅读、听力只显示基于客观题的正确率；写作与口语在没有可靠评分器前不生成虚假能力百分比。
- 学习状态保存在浏览器 localStorage；口语录音保存在 IndexedDB；支持 JSON 学习备份导出/导入。

## 文件结构

- `index.html`：页面入口
- `styles.css`：视觉与响应式样式
- `data-a.js` / `data-b*.js`：基础课程与 DELF 参考数据
- `app-a*.js` / `app-b.js`：基础训练、存储、录音与交互逻辑
- `v13-p*.js`：V1.3 强度配额、分阶段题库、自动完成度与内容深化

## 进度评估原则

初始化为 0 / 未评估。只有实际答题、写作提交、应用提交、口语录音或任务完成后才更新记录。口语目前记录真实训练次数和录音时长，不将完成次数伪装成口语水平。

## 参考框架

课程结构参考 France Éducation international 的 DELF B1 官方要求、CEFR 行动导向框架，以及主流 FLE B1 教材的语法与任务组织方式。本站不复制或重新发布受版权保护的教材和正式考试题。
