# DELF50 Web

A1+ → DELF B1 的 50 天网页备考训练系统。

## 当前版本

V1.7.0

生产地址：`https://delf50-mvp.vercel.app`

## V1.7 目标

V1.7 把产品从“功能原型”推进为可长期扩展的教学系统，重点解决三件事：

1. 50 天课程不再只有阶段标题，而是逐日给出 Can-do、语法/功能、前置复习、输入、输出、检查点和设计依据。
2. 主界面按教学使用习惯重构，版本/技术说明从学习主页移出，增加“今日课程”“50天路线”“资料与来源”等教学入口。
3. 所有课程材料和题目建立 provenance 追溯信息，区分官方依据、语言规范参考、外部拓展资源和 DELF50 原创训练内容。

## 50 天路线

- Day 1–18：基础与语法自动化。A1+ → A2/A2+，重点是现在时、否定、提问、过去时、未来、代词、关系代词、比较、条件式和连接词的主动调用。
- Day 19–30：应用迁移。叙事、请求、建议、投诉、比较、观点、书面互动、阅读定位和听力策略。
- Day 31–40：DELF B1 四项专项。听力、阅读、写作 ≥160 词、三类口语任务和 Mini-mock。
- Day 41–50：模拟与修复。Mock、错误分类、定向修复、输出速度、Final mock 与考前轻复习。

机器可读课程数据保存在：

- `content/curriculum-v17.json`
- `content/source-catalog-v17.json`
- 运行时教学层：`v17-pedagogy.js`

## 每日强度

- 5 小时：语法客观题 8、主动产出 6、应用 2、听力 2、阅读 2、写作 1、口语 2。
- 6.5 小时：语法客观题 10、主动产出 8、应用 3、听力 3、阅读 3、写作 1、口语 3。
- 8 小时：语法客观题 12、主动产出 10、应用 4、听力 4、阅读 4、写作 2、口语 4。

高强度只增加当前阶段的不同材料、重复调用和复盘，不通过越级引入后续语法来凑时间。

## 来源与可追溯性

每个内容项拥有稳定 `traceId`，例如：

- `GQ-present-01`：语法题
- `READ-r16-01`：阅读篇章
- `RQ-r16-01-1`：阅读篇章中的问题
- `LIST-l16-01` / `LQ-l16-01-1`：听力脚本及其问题
- `WRITE-*` / `SPEAK-*` / `APP-*`：写作、口语和应用任务

`provenance` 包含：

- `traceId`
- `kind`
- `author`
- `basis`：设计依据 sourceId
- `extension`：拓展学习 sourceId
- `note`：版权和内容性质说明

当前自动审计覆盖语法节点/题目、阅读/听力篇章和问题、写作、口语和应用任务。V1.7 目标覆盖率为 100%。

### 来源原则

- France Éducation international：用于 DELF B1 考试结构、官方样题格式、评分与备考要求对齐。
- Council of Europe CEFR：用于 B1 Can-do、reception / production / interaction 和行动导向课程设计。
- Académie française：用于规范法语和词义查证。
- RFI / TV5MONDE：作为真实输入的拓展学习链接，不复制其文章、音频或练习正文。
- DELF50 自编题目明确标记“DELF50原创训练材料”，不称为官方题或官方真题。

更完整的内容规范见 `docs/content-model.md`。

## 内容规模

当前基础内容池包括：

- 18 个高收益语法节点，重点节点约 10–12 道客观题，并配主动产出。
- 阅读 24 篇。
- 听力 24 组。
- 写作 24 项。
- 口语 24 项。
- 应用情境 24 项。

这些内容继续按 Day 解锁。后续扩展应优先增加同阶段材料和题型多样性，而不是直接打乱 50 天课程依赖关系。

## 教学界面

学习主页只显示：

- Day / 阶段 / Can-do
- 当前语法、功能、主题
- 今日输入/输出目标
- 5 / 6.5 / 8 小时学习强度
- 每个学习块真实完成数
- 前一天 / 下一天 / 50天路线

“资料与来源”是独立页面，默认不把长来源说明堆在学习正文中。具体篇章/题目旁只显示简短来源 ID，点击后再展开设计依据和拓展链接。

## 进度评估原则

初始化为 0 / 未评估。

- 语法 / 阅读 / 听力：只用真实客观题样本计算正确率。
- 写作：记录文本、字数、结构与完成次数；未接可靠评分器前不伪造 DELF 分数。
- 口语：记录录音、训练时长、任务次数和回听证据；未接可靠法语 ASR + DELF 评分器前不生成口语水平百分比。
- 提前进入未来 Day 不会自动补齐过去 Day，也不会提升能力指标。

## 存储

- `localStorage`：学习状态与进度。
- `IndexedDB`：口语录音。
- JSON 导出/导入：学习状态备份与迁移。

升级 V1.7 沿用现有学习数据 key，不主动清空用户进度。

## 稳定启动

首屏静态 HTML 永远可见。浏览器仍沿用已通过用户测试的 13/13 启动链；全部资源到齐后才按固定顺序执行。V1.6 内容层和 V1.7 教学层由 Vercel 服务端附加到最后一个内容模块，在返回浏览器前进行 JavaScript 编译检查，因此不会增加客户端启动模块数量。
