# DELF50 Web

A1+ → DELF B1 的 50 天网页备考训练系统。

## 当前版本

V1.5.1

当前生产地址：`https://delf50-mvp.vercel.app`

## 核心原则

- 每日学习强度可选 5 小时 / 6.5 小时 / 8 小时。
- 强度变化真实联动语法、听力、阅读、写作、口语、应用、词块与复习题量。
- 语法训练不只做选择题，同时记录主动造句、改写与口头调用训练证据。
- Day 1–18：A1+ → A2/A2+ 基础与语法自动化。
- Day 19–30：应用迁移。
- Day 31–40：DELF B1 四项专项。
- Day 41–50：模拟、错因定位与提分。
- 用户可以提前浏览或学习后续 Day，但不会自动补齐之前进度。
- 语法、阅读、听力只显示基于客观题的正确率；写作与口语在没有可靠评分器前不生成虚假能力百分比。
- 学习状态保存在浏览器 localStorage；口语录音使用 IndexedDB；支持 JSON 学习备份导出/导入。

## V1.5.1 稳定启动机制

首屏静态 HTML 永远可见，不依赖 JavaScript 成功启动，因此资源异常时也不会白屏。

完整交互由 13 个版本化模块组成。浏览器从 Vercel 同域 `/api/source` 预取全部模块；只有 13/13 全部成功后才按固定顺序启动。`api/source.js` 在 Vercel 服务端从固定 GitHub 提交读取资源，并先执行 JavaScript 编译检查。任何模块失败时网页保留静态学习计划并显示错误，而不是进入半加载状态。

## 每日强度配额

- 5 小时：语法客观题 8、主动产出 6、应用 2、听力 2、阅读 2、写作 1、口语 2。
- 6.5 小时：语法客观题 10、主动产出 8、应用 3、听力 3、阅读 3、写作 1、口语 3。
- 8 小时：语法客观题 12、主动产出 10、应用 4、听力 4、阅读 4、写作 2、口语 4。

高强度只增加当前阶段的重复、输入与输出，不提前引入未来阶段的新语法。

## 进度评估原则

初始化为 0 / 未评估。只有实际答题、写作提交、应用提交、口语录音或任务完成后才更新记录。口语目前记录真实训练次数和录音时长，不将完成次数伪装成口语水平。

## 参考框架

课程结构参考 France Éducation international 的 DELF B1 官方要求、CEFR 行动导向框架，以及主流 FLE B1 教材的语法与任务组织方式。本站不复制或重新发布受版权保护的教材和正式考试题。
